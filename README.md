# halloween-issues

Repositorio para reportar bugs del proyecto de Halloween.

Aquí no hay código: solo issues. Si algo no funciona como debería, abre un issue y lo revisamos.

## Cómo reportar un bug

1. Revisa los [issues abiertos](../../issues) por si ya lo ha reportado alguien.
2. Abre un [nuevo issue](../../issues/new/choose) y rellena el formulario.
3. Indica siempre:
   - El **navegador y su versión** (Chrome, Firefox, Safari, Edge...).
   - Una **captura de pantalla o un vídeo** donde se vea el problema.
   - Los **pasos para reproducirlo**.

Los issues sin navegador ni captura o vídeo no se pueden revisar y se cerrarán.

## Consejos para adjuntar la captura o el vídeo

- Arrastra el archivo (imagen o vídeo) dentro del campo del formulario, o pégalo directamente con `Ctrl + V` / `Cmd + V`.
- Formatos admitidos: `.png`, `.jpg`, `.gif`, `.mp4` y `.mov`.
- Si es un vídeo, intenta que dure poco y muestre los pasos desde el principio hasta que aparece el error.

## Normas

- Un issue por bug.
- Escribe un título claro y descriptivo.
- Sé respetuoso con el resto de la comunidad.
